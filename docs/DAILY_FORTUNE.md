# 오늘의 PLAY 운세 — /today 무료 모드

사업 목적: 검색 유입 → 무료 오늘운세 → 기존 무료 사주 결과 → 기존 유료 상세 리포트. 오늘운세에는 결제나 제한을 넣지 않는다. 별도 프레임워크/패키지 없이 기존 TypeScript 앱·정적 HTML 빌드를 재사용한다.

계산: 기존 일주·십성 함수로 내 일간과 오늘 천간·지지 정기를 비교하고, 확정된 원국의 각 기둥과 오늘 일진 사이의 천간합/충·지지육합/충을 기존 findRelations로 계산한다. 미확정 기둥·미상 시주는 제외한다. 한국 시간 00시 기준이며 동일 명식·날짜에 동일 결과가 나온다. 60갑자 주기는 반복되므로 매일 영구적으로 새로운 문구를 생성하는 서비스는 아니다.

- 오늘 TIER·총점, 재물·애정·업무·인간관계·컨디션 점수와 설명, 테마·작은 미션·계산 근거를 표시한다.
- 점수는 검증된 길흉 확률이 아닌 Beta PLAY 편집 규칙이다. 기본 60 + 천간 분야 가중치×4 + 지지 분야 가중치×2 + 합·충 보정(합 건당 +2/충 건당 -2, 최대 ±6), 0~100으로 제한한다. 분야 순서는 재물/애정/업무/관계/컨디션. 가중치 표는 src/lib/daily/reading.ts의 WEIGHTS에 공개되어 있고 실제 적용값은 화면 근거에도 표시한다. 총점은 5분야 평균. 오늘 TIER는 A≥80, B≥70, C≥60, D<60이다. 기존 팔자 TIER 기준을 재사용하거나 변경하지 않는다.
- 일주가 확정되지 않은 결과에는 해석을 생성하지 않는다.
- 대운·용신·전체 원국을 종합한 운세가 아닌 일간과 일진 관계의 Beta 해석이다. 문구는 편집 콘텐츠이며 외부 전문가 검토 전이다.
- 기존 사주 계산 결과·점수·티어·배틀·결제·환경 설정을 변경하지 않는다.
- 입력 구조는 기존 양력·KR·1962년 이후·성별·출생시간/모름을 그대로 사용한다. 음력 변환은 추가하지 않는다.
- 기존 사주 프로필 저장은 없었다. 선택한 사용자에 한해 palja-input-profile-v1에 생년월일·시간·성별 등을 이 기기에 저장한다. 기본은 저장 안 함. 재방문 시 유효성 검사 후 입력을 재사용한다. 삭제는 이 키만 제거하며 구매 복구 저장을 건드리지 않는다. 저장 차단은 계산을 막지 않는다. 서버에 신규 개인정보 저장/전송 없음. DST 중복 시각은 재방문에도 기존 선택 단계를 다시 요구한다.
- 한국 시간 날짜가 바뀐 뒤 탭으로 돌아오면 갱신한다. 화면의 날짜 확인 버튼으로도 갱신할 수 있다.
- 오늘 운세 전용 SNS 공유는 이번 범위에 포함하지 않는다.
- /today는 독립된 공개 설명 콘텐츠와 기존 입력/앱 번들을 사용한다. title/description/canonical/OG/robots는 기존 SEO helper를 사용하며 sitemap 기존 구조에 /today만 추가한다. FAQ 구조화 데이터는 추가하지 않는다. 숨은 키워드 없음.
- AdSense는 소유권 meta/ads.txt만 생성하는 현 상태를 보존한다. 새 광고 스크립트나 수동 슬롯을 넣지 않는다. 카드 사이 구조를 추후 광고 검토에 활용할 수 있지만 승인·광고 수익은 미확인이다.
- 기존 Supabase 이벤트 DB CHECK를 변경하지 않기 위해 today_page_view는 landing_view, today_fortune_generated/today_to_saju_click은 result_view에 mode=today와 props.action으로 기록한다. GA4 SDK·DB migration 없음. 오늘 모드의 분석은 mode/action으로 필터링해야 한다. 실제 운영 이벤트 저장 확인은 배포 후 필요하다.
- 기존 결과의 오늘운세 카드는 간략히 유지한다. /today의 상세 결과에서 CTA를 누르면 메모리의 계산 결과를 그대로 기존 결과에 넘겨 공유·배틀·Premium 흐름을 유지한다.

검증은 docs/WORKLOG.md 최신 항목 참조. 별도 feature/daily-fortune 브랜치이며 운영 Production/main/LIVE/환경 변수/DNS 변경 없음. 실제 Production /today 및 실결제·실기기·실제 SNS 전송은 확인하지 않았다.

관련 파일: src/lib/daily/reading.ts, tests/daily.test.ts, tests/profile.test.ts, web/src/profile.ts, web/src/main.ts, web/index.html, web/today-content.html, scripts/build.mjs, scripts/e2e.mjs, scripts/check-today.mjs, docs/DAILY_FORTUNE.md, docs/WORKLOG.md.

## 2차 UI·문구 개선

- 계산 파일과 공식은 변경하지 않는다. web/src/dailyCopy.ts는 이미 계산한 결과를 사용자용 표현으로 바꾸는 함수다. 동일 입력·날짜의 문구는 동일하고 원본 결과를 변경하지 않는다.
- /today 상세 결과만 점수 → 오늘 TIER → 한 줄 총평 → 총운(2문장) → 다섯 분야(점수/게이지/핵심 한 줄/2~3문장) → 퀘스트 → 계산 근거 순서로 보여준다. 기존 사주 결과의 간략 카드는 유지한다.
- 재물운·애정운 뒤에 중간 CTA를 한 번 넣고 하단 CTA를 유지한다. 동일한 goToSaju로 재입력 없이 기존 사주 결과로 이동한다.
- 퀘스트는 중심 십성별 행동 한 개이며 보상·출석 기능은 없다. 행운 숫자·색·시간은 현재 계산에 근거가 없어 제외한다.
- 하단에서 한국 시간 밤 12시 일진 변경과 내일 재방문을 안내한다. 점수/TIER가 반드시 매일 바뀐다고 약속하지 않는다. 의미 없는 예약 버튼은 추가하지 않는다.
- SEO 입력 전 정적 콘텐츠/메타/sitemap/robots/AdSense/ads.txt/환경변수/결제/기존 공유·배틀은 변경하지 않는다. 오늘 결과 클래스만 남색·골드 디자인 토큰을 재사용한다.
- 새 파일: web/src/dailyCopy.ts, tests/daily-copy.test.ts. 수정: web/src/main.ts, web/index.html, scripts/e2e.mjs 및 이 문서·WORKLOG. 별도 feature 브랜치이며 배포 전 검수 대기다.

## 개인 결과 압축

- 계산 원본·점수·TIER와 입력 전 공개 SEO 콘텐츠를 그대로 유지한다.
- 다섯 분야의 긴 보조 설명을 점수 구간에 맞춘 한 문장으로 줄인다. 중심 십성별 핵심 한 줄은 유지한다. 총운은 기존 2문장이고 퀘스트는 행동 제목만 보여준다.
- 결과 카드의 여백만 조금 줄이며 본문 글자 크기는 줄이지 않는다. 전문 설명은 기본 접힌 도움말이다.
- 중간/하단 CTA 문구와 연결, 재방문 안내, 기존 사주·Premium·결제는 유지한다. 읽기 시간 1~2분은 UX 목표이며 실제 사용자 독서 시간 측정은 하지 않았다.
- 동일한 390px 모바일·동일 입력으로 V2 및 압축본 전체 PNG의 높이를 비교한다. 측정 결과는 WORKLOG 최신 항목 참조.
