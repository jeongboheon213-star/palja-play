# /today 오늘운세 V2 — 실제 사주 근거 표시 (감사·설계·구현)

기준: Production `chatgpt/payment-tier-phase2` @ 0bfc80e (원격에서 직접 확인). 작업 브랜치 `claude/today-v2`. Production 배포 없음.

## 1. 감사: 현재 엔진이 실제로 쓰는 것 (`src/lib/daily/reading.ts`)
| 구분 | 사용 여부 |
|---|---|
| 원국 일간(천간) | 사용 — 오늘 글자와의 십성 기준 |
| 원국 연·월·일·시주 천간/지지 | 사용 — 확정(confirmed)된 기둥만 오늘 일진과 합·충 비교 |
| 시간 미상 | 시주 null → 비교 제외. 일주 미확정이면 오늘운세 자체를 만들지 않음 |
| 원국 지장간·원국 십성·오행 분포·음양 | 사용 안 함 (음양은 십성 계산 내부에서만) |
| 오늘 천간 / 오늘 지지 | 사용 (`dayPillarForDate`, KST 날짜) |
| 오늘 지지 정기(본기) | 사용 — `mainHiddenStem` 으로 지지 십성 계산 |
| 천간합·천간충·지지육합·지지충 | 사용 (`findRelations` 결과 중 이 4개만 필터) |
| 지지형·지지파·지지해·반합 | `findRelations` 가 계산은 하지만 오늘운세에서 **필터로 버림** (노출 안 함) |
| 삼합·방합 | 두 기둥 비교라 발생 불가 |
| 성별 | 오늘운세에 쓰이지 않음 (같은 명식이면 남녀 동일) |
| 용신·희신·기신·격국·신강약·12운성·대운·세운 | 계산하지 않음 → 사용 금지 |

점수식(코드 = 문서 일치 확인): 분야점수 = clamp(0~100, 60 + 천간십성가중치×4 + 지지십성가중치×2 + 합충보정). 합충보정 = 합 수×2 − 충 수×2, ±6 제한, **5개 분야에 똑같이** 적용. 총점 = 5분야 평균(반올림). 오늘 TIER A≥80 B≥70 C≥60 D. 가중치표 `WEIGHTS`(재물/애정/직장/관계/컨디션).

문구(`web/src/dailyCopy.ts`, `dailyNarratives.ts`): 십성(천간·지지 중 가중치 영향이 큰 쪽)×분야별 편집 문장 + 일부 십성 조합(blend) + 점수 구간 톤. 합·충은 **5분야 중 한 곳**(점수 최저/최고)의 문장만 바꿈. 같은 점수라도 십성이 다르면 문장은 다르다(기존 테스트 A·B·C).

### 두루뭉실하게 느껴지는 원인
1. 근거(십성·합충 이름)가 결과 화면에 없고 접힌 "어떻게 만들었나요?" 안에만 있음 — 문장이 무엇에서 나왔는지 사용자가 알 수 없다.
2. 합·충이 있어도 한 분야 문장에만 반영되고, 어느 기둥과 무엇이 부딪혔는지 말하지 않음 (점수 보정은 5분야 전부에 들어가는데 설명은 1곳).
3. 분야 문장은 십성×분야 50종 편집문이라, 같은 십성의 날에는 누구나 같은 문장 (일간이 같고 일진이 같으면 동일).
4. 분야별 행동 제안이 십성과 무관한 고정 문장(AREAS action)이었고, 상세 화면에는 분야별 행동이 없음.
5. 점수가 어떤 근거로 몇 점 더해졌는지 보이지 않음.

## 2. 노출 분류
- A. 직접 노출: 오늘 천간 십성, 오늘 지지(정기) 십성, 원국 기둥별 천간합·지지육합·천간충·지지충, 합·충 없음, 비교한/제외한 기둥, 분야별 점수 계산식.
- B. 계산은 하지만 추가 검증 전 노출 안 함: 지지형·지지파·지지해·반합(오늘↔원국), 원국 지장간, 원국 십성 분포.
- C. 계산하지 않음 → 사용 금지: 용신·희신·기신·격국·신강/신약·12운성(원국용으로만 unverified 존재, 해석 비연결)·대운·세운.

## 3. V2 구현 (`src/lib/daily/explain.ts`, 화면 `web/src/main.ts`)
점수·TIER·기존 문장은 그대로 두고 설명 계층만 추가.
- 총점/TIER 아래 **"🧭 오늘 내 사주에 들어온 흐름"**: 칩(정재 / 합 🤝 연주 / 충 ⚡ 월주 / 합·충 없음) + 항목별 쉬운 설명. 같은 종류 합·충은 한 항목으로 묶음. 비교한 기둥과 제외 이유(출생시간 모름 등) 표시.
- 분야 카드: 점수 → 핵심 한 줄(기존) → **근거 한 줄**(그 분야 점수에 더 크게 작용한 십성 + 합·충 칩, 가중치 크기와 맞춘 표현: 크게 올렸어요/올렸어요/조금 더해졌어요/더하지 않았어요/낮게 잡혔어요) → 기존 설명 → **🎯 오늘의 PLAY**(십성×분야 50종) → **점수 계산식**(기본 60 · 천간 정재 +16 · 지지 정재 +8 · 합·충 +2 = 86).
- ↑/↓ 아이콘은 쓰지 않음: 편재·편관 등은 좋고 나쁨이 아니라 관계 이름이므로 "↑"가 길함으로 오해될 수 있음. 대신 중립 칩, 합은 🤝, 충은 ⚡ + "나쁜 일이 생긴다는 뜻은 아니에요".
- 단정 금지 표현·미계산 용어는 테스트로 차단.

## 4. 남은 위험
- 십성·합충 의미 설명과 50개 근거/행동 문장은 편집 콘텐츠이며 외부 명리 전문가 검토 전.
- 합·충 보정은 5분야 동일 적용이라 "어느 분야에 특히" 라고 말할 근거가 엔진에 없다 → 분야별 합충 해석은 만들지 않았다.
- 화면 길이 증가(390px 기준 전체 높이는 WORKLOG 참고). 실기기(iPhone Safari 등) 확인 전.
- 대표 명식 비교표: `docs/TODAY_V2_SAMPLES.md` (`npx tsx scripts/inspect-today-v2.ts`).
