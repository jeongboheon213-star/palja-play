### 1. 문구 선택

- 기존: 천간 십성 10종 핵심 문장, 점수 3구간 보조 문장, 분야별 고정 추가 문장.
- 개선: 분야별 의미 단위 10종에 천간·지지 정기 십성을 모두 적용한다. 두 관계가 같으면 공통 초점, 다르면 두 관점을 함께 서술한다. 미리 100개의 긴 조합 문장을 쓰지 않는다.
- 기존 일간에서 계산된 두 십성을 사용한다. 일간은 근거로 표시하며, 일간별 성격/사건 규칙을 새로 만들지 않았다.
- 합만/충만/합과 충/없음으로 문장의 연결·조정 표현을 바꾼다. 발생 기둥은 총운의 사실 설명과 펼쳐보기에서 읽을 수 있다. 위치를 연애·자녀·재산 사건에 연결하지 않는다.
- 점수는 <60 / 60–64 / 65–69 / 70–74 / 75 이상에서 확인/조율/작은 실천/범위를 정한 시도/실행과 점검의 톤만 바꾼다. 점수 공식과 TIER는 동일하다. 모든 인접 점수마다 문장이 달라지지는 않는다.
- 행동 문장은 해당 분야의 기존 가중치 기여(천간×4, 지지×2)를 비교해 더 큰 쪽의 십성 조언을 선택한다. 같으면 천간을 사용한다. 새로운 점수나 의미 가중치를 만들지 않았다.
- 각 분야에 일간·두 십성·모든 합충 종류와 위치·점수·행동 초점의 evidenceIds를 남긴다. 외부 전송하지 않는다.

### 2. 분야별 맥락

돈: 선택·예산·자원·조건. 애정: 감정·표현·약속·도움. 일: 아이디어·완성·역할·마감·학습. 인간관계: 의견·부탁·감사·책임. 컨디션: 일정·휴식·수면·회복 여유. 십성에 연결된 기존 테마를 이 맥락으로 번역하며 의료·투자·사건 예언을 만들지 않는다.

기존 닫힌 details 안에 내 일간, 오늘 일진, 천간 십성, 지지 정기 십성, 합/충 개수, 실제 원국 기둥과 관계 종류, 보정, 다섯 점수를 표시한다. 상세 계산 공식/가중치/Beta 안내 유지. 기본 화면에 십성을 다섯 번 나열하지 않는다.
