# PLAY 티어 기준 0.1.0

기존 점수 `score-0.1.0`과 배틀 승패 공식은 변경하지 않는다. 티어는 별도의 표시 계층이다.

## 실제 실행한 기준분포

`scripts/analyze-tier-distribution.ts`로 1962-01-01~2026-12-31의 모든 날짜, 12개 시간대(00:30부터 두 시간 간격), 남성·여성을 같은 비중으로 계산했다. 날짜 23,741 × 시간 12 × 성별 2 = 569,784건 중 유효 결과 569,776건이다. 서머타임 존재하지 않는 시각 4건과 중복 시각 4건은 임의 보정 없이 제외했다.

초기 5일 간격·4개 시간대 분석은 60일 주기의 일부 일주와 시간대에 편향될 수 있어 최종 기준으로 채택하지 않았다. 점수 엔진은 유지하고 표본 방법만 개선했다.

종합점수는 7개 기존 점수의 동일 가중 평균을 반올림한 값이다. 실제 범위 37~82점, 평균 62.879점, 중앙값 63점이다. 분석 결과와 0~100점별 빈도는 `docs/tier-distribution.json`에 저장했다.

## 등급

게임 등급의 목표 구간은 상위 1/5/15/35/60/85%다. 아래 **점수 경계는 실제 빈도에서 계산한 결과**이며 임의 점수로 지정한 것이 아니다. 동점은 동일 등급이고, 실제 등급별 인원 비율은 목표 비율과 다를 수 있다.

| 종합 티어 | 종합점수 | 해당 등급 최소점수의 동점 포함 상위 비율(올림) |
|---|---|---|
| S+ | 79 이상 | 1.0% |
| S | 76~78 | 4.8% |
| A+ | 72~75 | 14.8% |
| A | 67~71 | 34.3% |
| B+ | 62~66 | 57.2% |
| B | 55~61 | 84.6% |
| C | 54 이하 | 각 점수의 실제 빈도로 계산 |

상위 비율 = 기준표본 중 **해당 점수 이상**의 표본 수 / 전체 유효 표본 수 × 100. 화면 숫자는 소수점 한 자리로 올림하여 순위를 과장하지 않는다. 등급은 반올림 전 비율로 결정한다. 표본 최대점수보다 높은 공유 점수는 ‘상위 0.1% 미만’으로 표시한다. 공유 점수는 사용자가 수정할 수 있으므로 순위 인증이나 보상을 의미하지 않는다.

능력치별 티어는 각 능력치의 별도 빈도표를 쓴다. TOP 능력치는 상대적 상위 비율이 가장 낮은 항목이며, 동률이면 기존 능력치 순서로 정한다. 점수가 몰린 능력치는 일부 등급이 비어 있을 수 있다. 동점을 난수로 나누지 않는다.

## 버전·재현

- 기준분포: `tier-reference-0.1.0`
- 등급 계산: `tier-0.1.0`
- `node scripts/build-tier-reference.mjs --check`: 저장된 빈도와 실행용 기준표의 일치 검사
- `node scripts/verify-tier-analysis.mjs FILE.json`: 재실행한 분석 결과 전체가 저장 결과와 같은지 검사
- 점수·표본·등급 정책이 바뀌면 새 버전과 새 분석 결과를 함께 검토한다.

## 표현과 한계

화면에는 ‘사주팔자PLAY 기준 상위 X%’만 표시한다. 실제 인구통계, 한국인 순위, 검증된 능력 측정값이 아니다. 일정 간격의 시각을 고르게 계산한 고정 표본이며 실제 출생시각 빈도와 다르다. 시간 미상 입력도 현재 엔진이 산출한 점수를 이 고정 기준에 비교하며, 별도 인구통계로 주장하지 않는다. 기존 절기·만세력 검증 상태는 그대로다.

배틀 URL에는 티어나 버전을 새로 넣지 않는다. 기존 `createBattleShare()`의 캐릭터·7개 점수·닉네임만 사용하고 표시할 때 티어를 계산한다. 기존 링크도 유지한다.
